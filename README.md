# Telegram-бот барбер-студии

Бот на **aiogram 3** принимает заявки клиентов, даёт выбрать барбера с рейтингом и ценой в долларах, умеет редактировать запись и регистрировать мастеров.

## Возможности

**Клиент**
- Запись: имя → телефон → услуга (цена в $) → барбер (рейтинг и сегмент Economy / Standard / Premium)
- Перед отправкой можно изменить имя, телефон, услугу и барбера
- В «Мои заявки» можно править или отменить заявку, пока барбер её не подтвердил
- Заявка уходит выбранному барберу, не «в общий котёл»

**Барбер**
- «Стать барбером» — анкета (имя, описание, ценовой сегмент)
- После одобрения администратором открывается «Кабинет барбера»
- В кабинете можно менять имя, описание, рейтинг, сегмент, цены услуг
- Входящие заявки: подтвердить, отклонить, сменить услугу/цену, завершить визит

**Администратор** (`ADMIN_ID`)
- При первом запуске сам появляется в списке барберов
- Одобряет, отклоняет и блокирует барберов
- Меняет их имя, рейтинг и сегмент
- Видит все записи и базовые цены студии

## Подготовка

1. Токен от [@BotFather](https://t.me/BotFather)
2. Свой Telegram ID, например через [@userinfobot](https://t.me/userinfobot)
3. Значения в `.env`:

```env
BOT_TOKEN=123456789:AA...ваш_токен
ADMIN_ID=123456789
```

## Запуск

Нужен Python 3.10+.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Данные хранятся в SQLite-файле `data/bot.db`.

Чтобы барбер получал заявки, он должен хотя бы раз написать боту `/start`.

## Как проверить

1. Админ: `/start` → в списке барберов будет «Studio Admin».
2. Со второго аккаунта: «Стать барбером» → заполнить анкету.
3. С аккаунта админа: «Админ-панель» → одобрить заявку.
4. Клиентом записаться, выбрать нового барбера и проверить, что заявка пришла ему.
5. В «Мои заявки» изменить имя или услугу до подтверждения.
